## Data Structures > Object > Size

### Object.keys().length

> Example: Get size of an object

Size of an object is the number of properties it holds.

```javascript
const myObj = {
  firstName: "Rahul",
  lastName: "Patil",
  age: 2049 - 2024,
};

let size = Object.keys(myObj).length;

console.log(size);
// 3

```
