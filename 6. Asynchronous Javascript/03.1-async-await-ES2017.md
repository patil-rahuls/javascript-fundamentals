## Asynchronous Javascript > Async/Await [ES2017]

> 🎯 `async/await` is modern syntactic sugar built on top of JavaScript promises. It allows you to write asynchronous code that reads and behaves like synchronous code, completely eliminating the need for `.then()` chains while keeping the main thread fully non-blocking.

---
&nbsp;

### 1. Introduction to Async/Await

An `async` function allows you to use the `await` keyword inside its body. The `await` keyword pauses the execution of the async function until the given Promise settles, without blocking the main execution thread.

```javascript
const myFunc = async function (page) {
  // await pauses execution here until fetch() resolves, 
  // but runs completely asynchronously in the background.
  const response = await fetch(".../api/users?page=" + page);

  // response.json() also returns a promise, so we await it too
  const data = await response.json();

  console.log(data);
};

myFunc(2);

console.log("This will be printed first.");

// Output:
// "This will be printed first."
// (After fetch completes, the data is logged below)
// {...}
```

### 2. Comparison: `async/await` vs `.then()`

To understand how `async/await` simplifies code, compare it to the equivalent `.then()` syntax:

```javascript
// Using async/await (Clean and synchronous-looking)
const myFunc = async function(page) {
  const response = await fetch(".../api/users?page=" + page);
  const val = await response.json();
  console.log(val);
};

// Equivalent using traditional .then() chains:
const myFuncOld = function(page) {
  fetch(".../api/users?page=" + page)
    .then(val => val.json())
    .then(val => console.log(val));
};
```

---

### 3. Handling Errors with `try...catch`

> ⚠️ **Important:** With traditional promises, we could append a `.catch()` method to the end of a `.then()` chain. However, you cannot chain `.catch()` onto an `eval` or `await` statement. Therefore, **always use `try...catch` blocks** inside `async/await` functions to properly intercept rejected promises or manual errors.

```javascript
const getDataSafely = async function (page) {
  try {
    const response = await fetch(".../api/users?page=" + page);

    if (!response.ok) {
      throw new Error("Failed with status: " + response.status);
      // Manually throwing an error immediately 
      // jumps execution down to the catch block.
    }

    const data = await response.json();
    console.log(data);

  } catch (err) {
    // Captures any errors thrown during fetch, json parsing, or manually
    console.error("Error caught: " + err.message);
  }
};

getDataSafely(2000);
```
