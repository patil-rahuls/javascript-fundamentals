## Asynchronous Javascript > Async/Await [ES2017] > **Returning Values**

> 🎯 **`async/await`** is simply syntactic sugar over the **`.then()`** method. 
> 
> Inside an **`async`** function, you can use one or more **`await`** statements.

---
&nbsp;

### 1. Returning a Value from an Async Function

```javascript
const myFunc = async function (page) {
  try {
    const response = await fetch(".../api/users?page=" + page);
    const data = await response.json();

    return data;
  } catch (err) {
    console.log(err.message);
  }
};

console.log("First");
const d = myFunc(2);
console.log(d);
console.log("Last");

// Output:
// First
// Promise {<pending>}
// Last
```

> ⚠️ **Important Note:**  
> It prints **`Promise {<pending>}`** instead of the final value because at that point in the code, JavaScript has no way of knowing the resolved value of `data` yet.


### 2. Comparing with the `.then()` Version

Observe the order in which the output is printed when using `.then()`:

```javascript
console.log("First");
// const d = myFunc(2);
// console.log(d);
myFunc(2).then((val) => console.log(val));
console.log("Last");

// Output:
// First
// Last
// {...}
```

### 3. Async IIFE (Immediately Invoked Function Expression)

You can also use an **async IIFE**:

```javascript
(async function () {
  try {
    const response = await fetch(".../api/users?page=" + page);
    const data = await response.json();

    console.log(data);
  } catch (err) {
    console.log(err.message);
  }
})();
```

**💡 Note:** Since this is an IIFE, you don’t need to manually throw an error.

> ⚠️ **Important Note:**  
> `await` can only be used inside an `async` function — and nowhere else.
