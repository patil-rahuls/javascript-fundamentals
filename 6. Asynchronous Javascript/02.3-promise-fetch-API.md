## Asynchronous Javascript > Promises & fetch API [ES6]

> 🎯 The `fetch()` API is a modern, promise-based way to make network requests. It provides a cleaner and more minimal alternative to traditional AJAX (`XMLHttpRequest`), allowing you to elegantly handle asynchronous data fetching by chaining `.then()` methods instead of nesting callbacks.

---
&nbsp;

### 1. Consuming a fetch() Promise

A perfect example of an asynchronous operation that returns a future value is fetching a response from an API. `fetch()` immediately returns a Promise object.

```javascript
const result = fetch("[https://reqres.in/api/users?page=2](https://reqres.in/api/users?page=2)");

console.log(result);
// Promise {<pending>}
```

To consume this promise, we chain the `.then()` method. When the network request completes, the promise resolves and passes a `Response` object to the callback. 

```javascript
result
  .then(function (response) {
    // callback for fulfilled promise
    console.log(response);

    // The response contains a 'Body' property (ReadableStream).
    // We use the json() method to parse the JSON data.
    
    return response.json(); 
    // Note: json() is also an asynchronous function and returns a NEW Promise.
  })
  .then(function (data) {
    // This then() consumes the promise returned by response.json()
    console.log(data);
  });
```

### 2. Cleaner Syntax with Arrow Functions

Using ES6 arrow functions makes the `fetch()` chain much simpler and more readable.

```javascript
const getData = () => {
  fetch("[https://reqres.in/api/users?page=2](https://reqres.in/api/users?page=2)")
    .then((response) => response.json())
    .then((data) => console.log(data));
};
```

> ⚠️ **Important:** Observe how we have chained the promises sequentially. This flattens the structure and completely avoids "Callback Hell".

### 3. Execution Flow Example

This example demonstrates the non-blocking nature of asynchronous code.

```javascript
(function () {
  console.log("Fetching Data asynchronously...");
  
  fetch("[https://reqres.in/api/users?page=2](https://reqres.in/api/users?page=2)")
    .then((response) => {
      console.log("Fetched Data");
      return response.json();
    })
    .then((data) => console.log(data));
})();

// Output:
// Fetching Data asynchronously...
// Fetched Data (Prints later, once the network request completes)
// {...} (The parsed JSON data)
```

### 4. Empty `.then()` Methods

If we do not pass any callback to a `.then()`, it is simply ignored. The resolved value passes straight through to the next chained `.then()` method.

```javascript
var p = new Promise(function (resolve, reject) {
  resolve("OK");
});

p.then()  // Ignored
 .then()  // Ignored
 .then(function (data) {
   // The last non-empty then() operates on the promise object p.
   console.log(data);
 });

// Output:
// "OK"
```
