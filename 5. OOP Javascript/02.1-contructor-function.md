## OOP Javascript > Constructor Functions

> 🎯 A **Constructor Function** is a regular JavaScript function used to create and initialize objects. By convention, they start with a capital letter and are invoked using the `new` keyword. **Arrow functions cannot be used as constructors** because they lack their own `this` binding.

---
&nbsp;

### 1. Basic Syntax and Usage

We create a constructor function just like a regular function. The `this` keyword inside it refers to the newly created object.

```javascript
const Student = function (name, rollNo) {
  this.name = name;
  this.rollNo = rollNo;
};

const stu = new Student("Rahul", 1);
```

*Here, `Student` is the Constructor Function, and `stu` is the newly created instance (object).*

### 2. The Prototype Relationship

Every function in JavaScript automatically gets a property called `prototype`. 

*Important: `Student.prototype` is **NOT** the Prototype Object of the `Student` constructor function itself. It is the prototype for all objects created **using** the `Student` constructor function (like `stu`).*

```text
////////////////////////////////////////////////////////////////////////////////////////////////////////////
//  _________________                                        _______________________
// |                 |----------- Student.prototype --------->|                       |
// | Constructor Fn. |                                        | Prototype (of "stu")  |
// |  [ Student() ]  |<---- Student.prototype.constructor ----|  [Student.prototype]  |
// |_________________|                                        |_______________________|
//                                                                         ^
//                                                        Prototypal       |
//                                            ^           Inheritance/     |  stu.__proto__
//                                            |            Delegation      |
//                            Prototype Chain |               _____________|________________
//                                            |               |                              |
//                                            |               |           Object             |
//                                                            |          ["stu"]             |
//                                                            | name     : "Rahul"           |
//                                                            | rollNo   : 1                 |
//                                                            | __proto__: Student.prototype |
//                                                            |______________________________|
//
////////////////////////////////////////////////////////////////////////////////////////////////////////////
```

`Student.prototype` has a property called `constructor` that points right back to the `Student()` function. When `stu` is created, its internal `__proto__` property is linked directly to `Student.prototype`.

### 3. Behind the Scenes: The `new` Operator

When you call a function with the `new` operator, four specific events happen automatically behind the scenes:

1. An empty object `{}` is created.
2. The `this` keyword in the constructor function is set to point to this newly created object.
3. The new object is linked to the constructor function's `prototype` property (this sets the `__proto__` property on the new object).
4. The new object is automatically returned from the constructor function call.

```javascript
const Teacher = function (name, empid) {
  // This will print an empty object of type "Teacher"
  console.log(this);
  // Teacher {}
};

// We call it with the "new" operator.
new Teacher("Rahul", 111);
```

### 4. The Method Anti-Pattern

While you *can* define methods inside a constructor function, you **should never do this**. If you create 1,000 instances of `Student`, each object will carry its own duplicate copy of the method, causing massive memory bloat.

```javascript
const Student = function (name, rollNo) {
  // Instance Properties
  this.name = name;
  this.rollNo = rollNo;

  // ❌ NEVER DO THIS: Method inside a constructor function.
  this.show = function () {
    console.log(this.rollNo, this.name);
  };
};

// We call it with the "new" operator.
const s1 = new Student("Rahul", 132188);

console.log(s1);
// Prints the Student Object containing a unique copy of show()
```

### 5. Checking Instances

Although we didn't technically create a class (as seen in other programming languages) and didn't instantiate it, it behaves exactly like one. We can verify that `s1` is an instance of `Student` using the `instanceof` operator.

```javascript
console.log(s1 instanceof Student);
// true
```
