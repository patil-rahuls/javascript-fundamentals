## OOP Javascript > Prototype Chain

> 🎯 The **Prototype Chain** is the mechanism by which JavaScript objects inherit features from one another. When you try to access a property or method on an object, JavaScript first looks at the object itself. If it can't find it there, it climbs up the chain to the object's prototype, and continues upward until it finds the property or reaches the absolute end of the chain (`null`).

---
&nbsp;

### 1. The Local Prototype Chain

When an instance is created, it links back to its constructor's prototype.

```text
////////////////////////////////////////////////////////////////////////////////////////////////////////////
//  _________________                                        _______________________
// |                 |----------- Student.prototype --------->|                       |
// | Constructor Fn. |                                        | Prototype (of "stu")  |
// |  [ Student() ]  |<---- Student.prototype.constructor ----|  [Student.prototype]  |
// |_________________|                                        |_______________________|
//                                                                         ^
//                                                        Prototypal       |
//                                            ^           Inheritance/     |  .__proto__
//                                            |            Delegation      |
//                            Prototype Chain |               _____________|________________
//                                            |               |                              |
//                                            |               |           Object             |
//                                                            |          ["stu"]             |
//                                                            | name     : "Rahul"           |
//                                                            | rollNo   : 1                 |
//                                                            | __proto__: Student.prototype |
//                                                            |______________________________|
//
////////////////////////////////////////////////////////////////////////////////////////////////////////////
```

### 2. The Complete Prototype Chain (Eagle's View)

Zooming out, we can see how the chain eventually leads all the way back to the core built-in `Object.prototype`.

```text
////////////////////////////////////////////////////////////////////////////////////////////////////////////
//         _________________            _______________________
//        |                 |          |                       | Object.prototype
//  ----> | Constructor Fn. |--------->|      Prototype        |  > constructor f
//  |     |  [ Object() ]   |          |  [ Object.prototype ] |  > ...                                            ^
//  |     |_________________|          |   __proto__ : null    |  > hasOwnProperty f <----------                   |
//  |                                  |_______________________|                               |                   |
//  |                                            ^                                             |                   |
//  |                                            |  .__proto__                                 |                   |
//  |      _________________            _________|_____________                                |                   |
//  |     |                 |          |                       |                               |                   |
//  |     | Constructor Fn. |--------->|      Prototype        |  This is an Object itself.    |                PROTOTYPE
//  |     |  [ Student() ]  |          |  [Student.prototype ] |  Remember every object in     |                 CHAIN
//  |     |_________________|          |     __proto__ :       |  JS has a prototype !         |                   |
//  |                                  |   Object.prototype    |                               |                   |
//  |                                  |_______________________|                               |                   |
//  |                                            ^                                             |                   |
//  |                                            |  .__proto__                                 |                   |
//  |                                   _________|_____________                                |                   |
//  |                                  |                       |                               |                   |
//  -- Built-in Constructor Fn.        |        Object         |                     method hasOwnProperty()       |
//    for objects. This is used        |        [ stu ]        |                     can now be accessed using     |
//    when we write an object literal  |      __proto__ :      |                     "stu" Object, because it      |
//     {...} = new Object(...);        |   Student.prototype   |                       is inherited from the       |
//                                     |_______________________|                      built-in Object.prototype    |
//
/////////////////////////////////////////////////////////////////////////////////////////////////////////////////
```

### 3. Traversing the Chain: An Example

Let's understand the execution of the following code based on the diagrams above:

```javascript
console.log(stu.hasOwnProperty("name"));
```

Just like the Scope Chain, JavaScript looks UP the Prototype Chain to resolve method calls:

1. **Check the Object:** The method `hasOwnProperty()` is called on the `stu` object. JavaScript checks if `stu` has this method directly. It does not.
2. **Check the Object's Prototype:** It looks up to `stu`'s prototype (which is `stu.__proto__`, pointing to `Student.prototype`). The method is not found here either.
3. **Check the Grand-Prototype:** It looks up to `Student.prototype`'s prototype (which is `Object.prototype`). The built-in `Object.prototype` *does* contain the `hasOwnProperty()` method, so it is found and executed.
4. **End of the Chain:** Note that `Object.prototype` has no prototype itself (`Object.prototype.__proto__` is strictly `null`). This is the absolute end of the Prototype Chain.

### 4. The Built-in Object Methods

`Object` is a built-in Constructor Function. All standard objects we create in JavaScript are ultimately instances of this `Object` constructor. 

Because of the Prototype Chain, the following methods defined on `Object.prototype` are delegated and automatically available to all objects:

*   `hasOwnProperty()`
*   `isPrototypeOf()`
*   `toString()`
*   `valueOf()`
*   `propertyIsEnumerable()`
*   `toLocaleString()`
