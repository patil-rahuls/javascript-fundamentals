## Functions > Timer Functions > `clearTimeout()`

> 🎯 The `clearTimeout()` method is used to cancel a scheduled timeout before it has a chance to execute. It accepts the unique timer ID (reference) returned by `setTimeout()` as its argument.

---
&nbsp;

### Canceling a Timeout

When you call `setTimeout()`, it returns a numeric timer identifier. You can store this reference and pass it into `clearTimeout()` to abort the scheduled execution—typically used inside conditional checks (such as canceling an auto-logout or a network request debounce).

```javascript
// 1. Schedule a timeout and store its reference ID
const myTimerFn = setTimeout(() => {
  console.log("Handler fn executed.");
}, 3000);

// 2. A condition to determine if we want to abort the timer
const someCondition = true; 

if (someCondition) {
  // Abort the timer before the 3 seconds elapse
  clearTimeout(myTimerFn);
  console.log("Timer has been successfully canceled.");
}
```

*If `someCondition` evaluates to `true`, `clearTimeout()` aborts the pending queue action, and `"Handler fn executed."` will never be printed to the console.*
