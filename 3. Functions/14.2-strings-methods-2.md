## Strings > More Methods

> 🎯 JavaScript provides an extensive set of built-in string methods to manipulate case, trim whitespace, replace content, evaluate substrings, split into arrays, and pad or repeat characters. Because these methods return new strings instead of modifying the original, they can be easily chained together.

---
&nbsp;

### 1. Changing Case: `toLowerCase()` & `toUpperCase()`

Converts the entire string to lower or upper case.

```javascript
const model = "Macbook Air";
console.log(model.toLowerCase()); // "macbook air"
console.log(model.toUpperCase()); // "MACBOOK AIR"

const name = "rAHUL";

// Combining methods and slicing
const newName = name[0].toUpperCase() + name.slice(1);
// "RAHUL"
```

### 2. `String.prototype.trim()`

Removes empty whitespace from both the beginning and the end of a string.

```javascript
const myStr = "   Hello World!   ";
const newStr = myStr.trim();
// "Hello World!"
```

### 3. Replacing Content: `replace()` & `replaceAll()`

*   **`replace()`**: Replaces only the *first* occurrence of a specified substring.
*   **`replaceAll()`**: Replaces *all* occurrences of a specified substring.

```javascript
let myStr = "Hello to the new world";

let newStr = myStr.replace("to", "with");
// "Hello with the new world"

newStr = myStr.replaceAll(" ", "_");
// "Hello_to_the_new_world"
```

**Method Chaining & Regex:**
A major advantage of string methods returning strings is that you can chain them directly. You can also use Regular Expressions (Regex) as an alternative.

```javascript
// Chaining multiple replacements
newStr = myStr.replace(" ", "_").replace("$", "Rs.");

// Alternative to replaceAll using Regex ('g' flag means global, applying to the entire string)
newStr = myStr.replace(/ /g, "_");
```

### 4. Checking Substrings: `includes()`, `startsWith()`, `endsWith()`

These methods evaluate the string and return a **boolean** (`true` or `false`).

```javascript
const myStr = "Rahul Patil";

// Checks if the string contains the given substring
myStr.includes("Patil"); // true

// Checks if the string starts with the given substring
myStr.startsWith("R"); // true

// Checks if the string ends with the given substring
myStr.endsWith("R"); // false
```

### 5. Splitting and Joining: `split()` & `join()`

*   **`split()`**: Explodes a string into an array based on a separator. This pairs perfectly with array destructuring.
*   **`join()`**: Implodes an array back into a single string using a separator. *(Note: `join()` is technically an Array method, but heavily used with strings).*

```javascript
const str = "Ubuntu's UI is ACTUALLY slow, Admit it!";
const resultArray = str.split(" ");
// ["Ubuntu's", "UI", "is", "ACTUALLY", "slow,", "Admit", "it!"]

// Destructuring arrays created by split()
const [firstName, lastName] = "Rahul Patil".split(" ");

// Using join() to reconstruct strings
const newName2 = ["Rahul", "Patil".toUpperCase()].join(" ");
// "Rahul PATIL"

const newName3 = ["Rahul", "Patil"].join("-");
// "Rahul-Patil"
```

### 6. Padding: `padStart()` & `padEnd()`

Pads the current string with another string until the resulting string reaches a specific length. Padding is added to the beginning (`padStart`) or the end (`padEnd`).

*Syntax:* `padStart(fixedLength, padCharacter)`

```javascript
const lol = "Barney Stinson";

console.log(lol.padStart(15, "+"));
// "+Barney Stinson" (Total length becomes 15)

console.log(lol.padStart(25, "+"));
// "+++++++++++Barney Stinson" (Total length becomes 25)

console.log(lol.padEnd(20, "-"));
// "Barney Stinson------"
```

> **Real-world Example:** Masking debit/credit card numbers.

```javascript
const maskCreditCard = function (number) {
  // Convert the parameter to a string using concatenation. 
  // Now it accepts both numbers and strings.
  let given = "" + number;

  // Get the last 4 digits
  const last = given.slice(-4);
  const len = given.length;

  // Pad the start with '*' until it reaches the original length
  const newVal = last.padStart(len, "*");

  console.log(newVal);
};

maskCreditCard(5674657210978324); // Accepts Number type
// "************8324"

maskCreditCard("1200987564738523"); // Accepts String type
// "************8523"
```

### 7. `String.prototype.repeat()`

Repeats a string a specified number of times and returns a new concatenated string.

> **Real-world Example:** Displaying UI rating icons.

```javascript
let rating = 4;

console.log(`You have got ${rating} rating \n${"🌟".repeat(rating)}`);
// You have got 4 rating 
// 🌟🌟🌟🌟
```
