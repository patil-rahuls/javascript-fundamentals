## Functions > Timer Functions > `setInterval()`

> 🎯 The `setInterval()` function repeatedly calls a callback function at a specified time interval (in milliseconds) continuously, running in the background until it is explicitly cleared.

---
&nbsp;

### 1. Basic Usage

In the following example, the callback function executes every 1 second (1000ms), printing the current date and time to the console indefinitely.

```javascript
setInterval(() => {
  const now = new Date();
  console.log(now);
}, 1000);
```

> ⚠️ **Note:** Because `setInterval` runs repeatedly without stopping on its own, it will continue to execute for the lifetime of the page/process unless you capture its timer ID and stop it using `clearInterval()`.
