## Functions > Timer Functions > `setTimeout()`

> 🎯 The `setTimeout()` function schedules a callback to be executed once after a specified number of milliseconds. It is non-blocking, meaning the rest of your code continues to run synchronously while the timer counts down in the background.

---
&nbsp;

### 1. Basic Usage

```javascript
setTimeout(() => console.log(`Started after 3 secs`), 3000);

console.log(`Waiting...`);
// 'Waiting...'
// (3 seconds later) -> 'Started after 3 secs'
```

*In the example above, `setTimeout()` registers the arrow function and immediately moves on to the next line. `console.log('Waiting...')` executes synchronously. Meanwhile, in the background, the timer waits for 3000 milliseconds before pushing the callback to the queue to be executed.*

---
&nbsp;

### 2. Passing Arguments to the Callback

> 🎯 If your callback function requires parameters, you can pass arguments directly into `setTimeout()`. Any arguments listed *after* the time delay will be fed directly into the callback function.

```javascript
setTimeout(
  (val1, val2) => console.log(`Values passed here are ${val1} and${val2}`),
  3000,      // Time delay in milliseconds
  "orange",  // Argument passed to val1
  "mango"    // Argument passed to val2
);

console.log(`Waiting...`);
// 'Waiting...'
// (3 seconds later) -> 'Values passed here are orange and mango'
```
