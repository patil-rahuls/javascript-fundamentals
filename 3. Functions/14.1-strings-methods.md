## Strings > Methods

> 🎯 JavaScript automatically converts string primitives into `String` objects behind the scenes when you call methods on them. This gives you access to a wide variety of built-in properties and methods to extract, search, and manipulate text easily, returning a new string primitive when done.

---
&nbsp;

### 1. Basic String Access

Just like arrays, strings are zero-indexed and have a `length` property.

```javascript
const brand = "Apple";
const model = "Macbook Air";

console.log(brand[0]);      // "A"
console.log("Apple"[0]);    // "A"
console.log("Apple"[3]);    // "l"
console.log("Apple".length);// 5
```

### 2. `String.prototype.indexOf()`

Returns the first index of a specified substring within a string. If the substring is not found, it returns `-1`.

```javascript
brand.indexOf("e");
// 4 

model.indexOf("Air");
// 8
```

### 3. `String.prototype.lastIndexOf()`

Returns the last index of a specified substring within a string. It searches the string backwards.

```javascript
brand.lastIndexOf("p");
// 2

"Mississippi".lastIndexOf("s");
// 6
```

### 4. `String.prototype.slice()`

Extracts a section of a string and returns it as a new string, without modifying the original string.

*Syntax: `slice(start_index, end_index)`*
*The character at `end_index` is **not** included in the returned result. The `end_index` is optional. Negative indexes count backward from the end.*

```javascript
model.slice(1);
// "acbook Air" (from index 1 to the end)

model.slice(-1);
// "r" (the last character)
```

### 5. The `splice()` Workaround

Because strings are immutable primitives in JavaScript, there is no `String.prototype.splice()` method. However, you can achieve the same result by converting the string to an array, using the array's `splice()` method, and joining it back into a string.

```javascript
// 1. Convert the String to an Array
let myStr = [...model];

// 2. Perform Array operations
myStr.splice(7);
// Removes elements from index 7 onwards. Returns ["A", "i", "r"]

// Note: If working from the original string again:
// myStr = [...model];
// myStr.splice(3, 7); 
// Removes 7 elements starting from index 3.

// 3. Convert the Array back to a string
myStr = myStr.join("");
```

### 6. Behind the Scenes: Primitives vs. Objects

*Important: JavaScript automatically converts a string primitive into a `String` object when you try to call a method on it.*

Once the method completes its operation on that object, the object is converted back into a string primitive and the result is returned. 

```javascript
// Explicitly creating a String object
console.log(typeof new String("rahul"));
// "object"

// When a method like slice() runs, it returns a primitive string
console.log(typeof new String("Rahul").slice(-1));
// "string"
```
