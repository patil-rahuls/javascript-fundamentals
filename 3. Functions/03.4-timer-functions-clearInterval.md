## Functions > Timer Functions > `clearInterval()`

> 🎯 The `clearInterval()` function is used to stop a repeating timer created by `setInterval()`. Without calling `clearInterval()`, the interval callback will continue running infinitely in the background, which can lead to performance degradation or memory leaks.

---
&nbsp;

### 1. Stopping an Interval

To clear an interval, you must pass the identifier (the variable storing the `setInterval` reference) into `clearInterval()`. 

> ⚠️ **Common Mistake:** Checking `if (max === 0)` **outside** the interval callback (as seen in synchronous code) will not work because the script executes immediately while the interval is still counting down. The check and the clearing logic must happen **inside** the callback or be triggered by an event.

```javascript
let max = 5;

const done = setInterval(() => {
  if (max > 0) {
    console.log(max);
    max--;
  } else {
    // Clear the interval once the countdown reaches 0
    clearInterval(done);
    console.log("Countdown complete!");
  }
}, 1000);
```

*   Every 1 second, the interval checks if `max > 0`.
*   Once `max` drops to `0`, `clearInterval(done)` is invoked, stopping the timer loop permanently.
