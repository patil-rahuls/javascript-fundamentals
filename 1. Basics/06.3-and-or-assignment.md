## Logical OR Assignment (**`||=`**)

> 🎯 Assigns the right operand to the left operand *only if* the left operand is **falsy**.

### 1. Setting Default Values
```javascript
let PORT = process.env.PORT;

// Equivalent to: PORT = PORT || 3000;
PORT ||= 3000;

console.log(PORT);
```

### 2. Short-circuit Object Property Initialization
```javascript
let settings = {};

settings.apiKey ||= "DEFAULT-KEY";

console.log(settings);
/*
{
  apiKey: 'DEFAULT-KEY'
}
*/
```

## Logical AND Assignment (**`&&=`**)

> 🎯 Assigns the right operand to the left operand *only if* the left operand is **truthy**.

### 1. Conditional Object Property Update
```javascript
let user = { name: "Rahul", isActive: true };

// Equivalent to: user = user && { ...user, isActive: false };
user &&= { ...user, isActive: false };

console.log(user);
/*
{
  name: 'Rahul',
  isActive: false
}
*/
```

### 2. Safe Event Handler Cleanup
```javascript
let listener = button.addEventListener("click", () => {
  console.log("Clicked!");
});

// Later: removes listener ONLY if 'listener' exists (is truthy)
listener &&= button.removeEventListener("click", listener);
```

### 3. Chained Object Checks
```javascript
let config = { theme: { darkMode: true } };

// Only overwrite if config.theme exists
config.theme &&= { darkMode: false };

console.log(config);
// { theme: { darkMode: false } }
```

### 4. Resetting a Cache Conditionally
```javascript
let cache = { items: [1, 2, 3] };

// Clear cache only if it exists
cache &&= null;

console.log(cache); 
// null
```
