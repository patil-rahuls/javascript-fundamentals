## Nullish Coalescing Operator (**`??`**)

> 🎯 It works exactly like the logical OR (**`||`**) operator, but it *only* considers **Nullish** values (**`null`** and **`undefined`**) as falsy.
>
> It does **NOT** consider the following as falsy:
> *   **`0`**
> *   **`""`** or **`''`** (Empty strings)
> *   **`NaN`**
> *   **`Infinity`**

---
&nbsp;
### 1. Preserving `0` as a Valid Value
When using **`||`**, a valid value of `0` gets overridden because it evaluates to falsy. 

A Nullish coalescing operator **`??`** prevents this.

```javascript
const usersCount = 0;

// ❌ using || overrides the valid 0
const maxUsers = usersCount || 10;
console.log(maxUsers); // 10

// ✅ using ?? preserves the valid 0
const maxUsersCount = usersCount ?? 10;
console.log(maxUsersCount); // 0
```

### 2. Preserving Empty Strings (`""`)
```javascript
const isDeleted = "";

const result = isDeleted ?? 1;
console.log(result); // '' (Empty string is preserved)
```

### 3. Handling `NaN` and `Infinity` _(⚠️ use `||` instead)_
Because **`??`** does not treat `NaN` or `Infinity` as falsy, it will return them rather than falling back. If you want to fall back to a default value in these cases, always use **`||`**.

```javascript
// ❌ ?? returns NaN and Infinity
const minUsers = NaN;
console.log(minUsers ?? 23); // NaN

const users = 1 / 0; // Infinity
console.log(users ?? 0);     // Infinity

// ✅ || correctly falls back to the default value
console.log(minUsers || 23); // 23
```
