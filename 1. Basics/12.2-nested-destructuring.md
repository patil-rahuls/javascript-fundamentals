## Nested Destructuring Assignment (ES6)

> 🎯 Unpacks and assigns values from arrays, or properties from objects into distinct variables.

---
&nbsp;

### 1. Nested Arrays

You can use empty commas to skip items, even at nested levels.

```javascript
const arr = [2, 4, 6, [1, 3, 5]];

// Extracting the nested array itself
const [i, , , j] = arr;
console.log(i, j); 
// 2   [1, 3, 5]

// Destructuring inside the nested array
const [, x, , [, , y]] = arr;
console.log(x, y); 
// 4   5
```

### 2. Nested Objects

When destructuring nested objects, you **MUST** use the exact property names (e.g., **`workingHours`**, **`weekdays`**, **`start`**, **`end`**) to navigate down the object tree.

```javascript
const user = {
  name: "Rahul",
  age: 25,
  city: "Pune",

  workingHours: {
    weekdays: {
      start: 10,
      end: 19,
    },
    weekends: {
      start: 12,
      end: 16,
    },
  },
};

// ✅ Correctly navigating and renaming nested properties
const {
  workingHours: {
    weekdays: { start: shiftStartsAt, end: shiftEndsAt },
  },
} = user;

console.log(shiftStartsAt, shiftEndsAt); 
// 10  19
```

#### The `TypeError` Trap
If you specify an incorrect property name while destructuring a nested object, JavaScript will try to read properties of **`undefined`**, resulting in an error.

```javascript
// ❌ Incorrect property ('monday' doesn't exist inside 'workingHours')
const {
  workingHours: {
    monday: {
      start: shiftStartsAt,
      end: shiftEndsAt,
    },
  },
} = user;

// ❌ Uncaught TypeError: Cannot read properties of undefined (reading 'start')
```

### 3. Destructuring Function Parameters

You can destructure objects directly in the function parameter list. This is highly useful for handling payloads or configuration objects.

```javascript
const user = {
  name: "Rahul",
  age: 25,
  city: "Pune",

  // ✅ Destructured Object as parameter
  notify({ name, msg }) {
    console.log(`${name} sent:${msg}`);
  },
};

const payload = {
  name: "Admin",
  msg: "Hello Rahul!",
};

// The 'payload' object is destructured right in the method definition
user.notify(payload); 
// "Admin sent: Hello Rahul!"
```
