## **let**, **const**, & **var** - Re-assignment

> 🎯 Difference 1 - Reassignment 
> *   **let** and **var** variables *can* be re-assigned.
> *   **const** variables *cannot* be re-assigned.
---
This strictness makes **const** the best choice for declaring variables that shouldn't change, as it prevents accidental re-assignment bugs.

&nbsp;

## Re-assigning **let** and **var**
Both allow their values to be updated after initialization.

```javascript
let a = 10;
a = 20; // ✅ Allowed

var b = "rahul";
b = "I just got re-assigned"; // ✅ Allowed
```

## Re-assigning **const**
Attempting to re-assign a **const** variable will throw a ***TypeError***.

```javascript
const c = 4.5;
c = false;
// ❌ Uncaught TypeError: Assignment to constant variable
```

However, for objects const **does allow mutation** _(not re-assignment)_.

```javascript
const myArr = [];

// ✅ Mutation is allowed (modifying the existing array)
myArr.push(1);
myArr[9] = 10;

// ❌ Re-assignment is NOT allowed (pointing to a new array)
myArr = [1, 2, 3];
// Uncaught TypeError: Assignment to constant variable
```
