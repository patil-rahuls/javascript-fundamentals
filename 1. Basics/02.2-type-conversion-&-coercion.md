## Type Conversion and Coertion

> Type Conversion is explicit.
>
> Type Coercion is implicit type conversion.

### 1. Type Conversion _(Explicit)_

```javascript
let age = 28;
console.log(typeof age);
// "number"

age = "28";
console.log(typeof age);
// "string"

```

&nbsp;

### 2. Type Coercion _(Implicit type conversion)_

```javascript
let str = "I am " + age;
// In this assignment, "age" gets converted from "number" to "string" type.

console.log(typeof age);
// "number"

```
&nbsp;

When we have all '**+**' operators in an expression and when one of the operands is a string, the operands after the FIRST string operand are coerced autmatically into string _(type coercion)_.

> Example
```javascript
console.log("23" + "10" + 3);
// '23103'

console.log("23" + "10" + 3 + 5);
// '231035'
 
console.log(4 + 1 + "5" + 6);
// '556'
 
console.log(1 + 3 + 5 + "5");
// '95'

```

Rest all mathematical operations work normally with type coercion applied automatically.

> Example
```javascript
console.log("23" - "10" - 3);
// 10

console.log("23" + "10" - 3);
// '2307'

```

---

&nbsp;

### Type coertion with Arrays _(Optional Read)_

> Example: _The **+** operator prefers strings if it can't find two numbers to add._

```javascript
let a = [1, 2, 3];
let b = a + 10;

console.log(b);
// '1,2,310' (string)

```

_In the above example, since one side is an array, JavaScript tries to convert that array into a **primitive** string. It does this by calling the array's **toString()** method._

_**[1, 2, 3].toString()** results in the string **"1,2,3"** followed by the string concatenation resulting in a string **"1,2,310"**._

### Number Type Conversion

**Loose Conversion** - converting a string loosely to a number.

**Number.parseInt()** extracts an _integer_ value from the START of the string or returns **NaN**.

```javascript
Number.parseInt("12");      // 12
Number.parseInt(12.345);    // 12
Number.parseInt("12.345");  // 12
Number.parseInt("aaa");     // NaN
Number.parseInt("");        // NaN
Number.parseInt("   ");     // NaN
Number.parseInt(" 2.3");    // 2
Number.parseInt("1   ");    // 1
Number.parseInt("foo2");    // NaN
Number.parseInt("12a5");    // 12

Number.parseInt("0x10");    // 16
// It allows you to specify a 'radix' for converting the string to an int.
// It considers '0x' as radix, making it as a hex value and returns its decimal equivalent (i.e. 16)

Number.parseInt("08");
// Radix is '0' i.e. an Octal number. Returns its decimal equivalent (i.e. 0)

```
---

**Number.parseFloat()** extracts a _floating-point_ value from the START of the string or returns **NaN**.

```javascript
Number.parseFloat("12.345");      // 12.345
Number.parseFloat("12.345abc");   // 12.345
Number.parseFloat("abc12.345");   // NaN
Number.parseFloat("");            // NaN
Number.parseFloat("   ");         // NaN
Number.parseFloat(" 2.3");        // 2.3
Number.parseFloat("1   ");        // 1
Number.parseFloat("foo2");        // NaN
Number.parseFloat("12a5");        // 12
Number.parseFloat("0x10");        // 0
// Number.parseFloat() does not considers any radix hence returns 0.

```

&nbsp;

**Strict Conversion** - converting a string strictly/fully to a number. Expects all characters in the string to be strictly numerical.

**Number()** does a strict conversion of a string to a number or returns **NaN** otherwise.

```javascript
Number("12.345");     // 12.345
Number("12.345abc");  // NaN
Number("abc12.345");  // NaN
Number("");           // 0
Number("   ");        // 0
Number(" 2.3");       // 2.3
Number("1   ");       // 1
Number("foo2");       // NaN
Number("12a5");       // NaN
Number("0x10");       // 16

```
