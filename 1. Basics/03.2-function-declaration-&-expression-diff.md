## Function Declaration & Expression - Differences

> 🎯 Differences
> *   **Function Declarations** are hoisted *before* any **`var`** declaration.
> *   **Function Expressions** are *not* hoisted (unless they use **`var`**, in which case only the variable name is hoisted).

---

## 1. Function Declarations _(Hoisted)_
Because function declarations are hoisted, a function can be called *before* it is defined in the file.

```javascript
const area = calcArea(34); // ✅ Works perfectly

// Function declared later
function calcArea(side) {
  return side ** 2;
}
```

## 2. Function Expressions _(Not Hoisted)_
By contrast, you can only call a function expression in a linear sequence. *You must define it before you call it.*

```javascript
const square = calcSQ(34); 
// ❌ Uncaught ReferenceError: Cannot access 'calcSQ' before initialization

// Function expression declared later
const calcSQ = function (side) {
  return side ** 2;
};
```
---

### 💡 Best Practice
**Always prefer Function Expressions.** 
Using function expressions enforces writing code in a logical, linear sequence _(i.e. declaring functions before using them)_. 

This prevents hoisting-related bugs and keeps code predictable, even without explicitly enabling `"use strict"`.
