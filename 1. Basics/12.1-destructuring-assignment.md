## Destructuring Assignment (ES6)

> 🎯 Unpacks and assigns values from arrays, or properties from objects, into distinct variables.

---
&nbsp;

### 1. Destructuring an Array

```javascript
const tech = ["JavaScript", "TypeScript", "Node.js", "Express", "React", "AWS Cloud"];

// ❌ Old way
let first = tech[0];
let second = tech[1];
let third = tech[2];

// ✅ Destructuring
[first, second, third] = tech;
console.log(first, second, third); // 'JavaScript' 'TypeScript' 'Node.js'

// Skipping elements (leave empty spaces between commas)
[, , , fourth] = tech;
console.log(fourth); // 'Express'
```

#### Default Values
When we don't know how many elements are in the array, missing values evaluate to **`undefined`**.

```javascript
let [p, q, r] = [8, 9];
console.log(p, q, r); // 8  9  undefined

// ✅ Solution: Define default values
[p = 1, q = 1, r = 1] = [8, 9];
console.log(p, q, r); // 8  9  1
```

---

### 2. Destructuring an Object

> ⚠️ **Important:** You must specify the *exact* property name in the destructuring assignment. This is highly useful for parsing API response data.

```javascript
const user = {
  name: "Rahul",
  age: 25,
  city: "Pune",
};

// ✅ Specify matching property names
const { name, age } = user;
console.log(name, age); // "Rahul" 25

// ❌ Incorrect property names result in undefined
let { role } = user;
console.log(role); // undefined
```

#### Default Values & Renaming Variables
In API calls, you might not know if certain data is present. You can assign default/fallback values or rename the variable.

```javascript
// Default/Fallback value
const { role = "Guest" } = user;
console.log(role); // "Guest"

// Renaming the variable (property: newName)
const { city: location } = user;
console.log(location); // "Pune"
```

---

### 3. Practical Use-Cases

#### Swap Two Values
*(Without using a temporary variable)*
```javascript
[first, second] = [second, first];
```

#### Mutate Existing Variables (Array)
```javascript
const myArr = [7, 8];
let a = 111, b = 999;

[a, b] = myArr;
console.log(a, b); // 7  8
```

#### Mutate Existing Variables (Object) - The "Parens Syntax"
```javascript
const myObj = { a: 91, b: 2, c: 3, d: 4, e: 5 };

let a = 111;
let b = 999;

// ❌ Syntax Error
{ a, b } = myObj; 
```
*Why the error?* The expression **`{ a, b }`** on the left-hand side is evaluated as a **block** instead of an object literal according to ES6 specifications.

```javascript
// ✅ Solution: Enclose the expression in parentheses "( )"
({ a, b } = myObj);

console.log(a, b); // 91   2
```
