## Short Circuiting **`&&`** and **`||`**

> 🎯 The operators **`||`** and **`&&`** do not always return a boolean. 
> 
> They return the actual value of one of their operands based on where the evaluation stops (short-circuits).
---

## 1. Logical OR (**`||`**)

> **Rule:** Keeps evaluating until a **truthy** value is found and returns it. If no truthy value is found, it returns the **last value**.

```javascript
// ✅ Returns the FIRST truthy value
console.log(undefined || 0 || "" || 'Hello' || 23 || null);
// 'Hello' (Short-circuits here)

// ✅ 3 is truthy, so the remaining expressions are skipped
console.log(3 || "");      // 3
console.log(3 || "Rahul"); // 3
console.log(true || 0);    // true

// ❌ Returns the LAST value if all are falsy
console.log(undefined || null);
// null
```

## 2. Logical AND (**`&&`**)

> **Rule:** Keeps evaluating until a **falsy** value is found and returns it. If no falsy value is found, it returns the **last value**.

```javascript
// ❌ Returns the FIRST falsy value
console.log(undefined && 0 && "" && 'Hello' && 23 && null);
// undefined (Short-circuits here)

// ❌ Stops at the first falsy value it hits in the chain
console.log("Hello" && 23 && null && "rest");
// null

console.log(0 && "Rahul");
// 0

// ✅ Returns the LAST value if all are truthy
console.log(3 && "Rahul");
// 'Rahul'
```

---

#### 💡 *Why is it called "Short-Circuiting"? (Optional Read)*

We call it short-circuiting because the evaluation process stops *as soon as the final outcome is mathematically guaranteed*. 

The name is a metaphor borrowed from electrical engineering, in which the current takes a shortcut and skips the rest of the loop when there is a short-circuit. 

Similarly, in JavaScript, the execution engine takes a shortcut and skips evaluating the rest of the expression to save processing time and prevent potential errors from unneeded evaluations.
