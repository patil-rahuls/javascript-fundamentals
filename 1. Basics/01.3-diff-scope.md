## **let**, **const** & **var** - Scope

**let** and **const** variables are **Block scoped**.
>
**var** variables are **Function scoped**.

_****Scope**** refers to the visibility or accessibility of variables and functions within different parts of a program. It determines where in the program a particular variable or a function can be accessed and manipulated._

_A block is any code within curly braces **{ }**, including functions, loops and conditional statements._

**let** and **const** variables are scoped to the immediate enclosing block denoted by **{ }** _(hence the **block scope**)_.

**var** variables are scoped to the immediate function body **function() {...}** _(hence the **function  scope**)_.

> Example 1

```javascript
function run() {
  // Function scope
  var foo = "Foo";
  let bar = "Bar";

  console.log(foo, bar);
  // 'Foo Bar'

  {
    // Block scope
    var moo = "Mooo";
    let baz = "Bazz";

    console.log(moo, baz);
    // 'Mooo Bazz'
  }

  console.log(moo);
  // 'Mooo'

  console.log(baz);
  // ❌ 'Uncaught ReferenceError: baz is not defined'
}

run();

```

&nbsp;

> Example 2

```javascript
var x = "global scope";

function foo() {
  var x = "function scope";
  console.log(x);
}

{
  let x = "block scope";
  // 'x' is only accessible in this enclosing block
}

foo();
// 'function scope'

console.log(x);
// 'global scope'

```

&nbsp;

> Example 3: Scope changes when a variable is declared without **let**, **var** or **const** keyword.

_In the following code, variable '**b**' is not declared using any of the **let**, **const** or **var** keywords and by default it becomes **globally scoped**._

```javascript
{
  let a = 9;
  b = 8; // becomes globally scoped
}

console.log(a);
// ❌ 'ReferenceError: a is not defined'
// (because 'a' is block scoped)

console.log(b);
// '8'
// (because 'b' is now globally scoped)

```

_**Globally scoped** means the variable is accessible by the global object._

_In Browser, '**b**' can be accessed using the browser's runtime's global object - **window**._

```javascript
console.log(window.b);

```

_In Node.js runtime, '**b**' can be accessed using Node.js runtime's global object - **global**._

```javascript
console.log(global.b);

```
