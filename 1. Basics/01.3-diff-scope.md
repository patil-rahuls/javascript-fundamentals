## **let**, **const** & **var** - Scope

> 🎯 Difference 2 - Scope 
> *   **let** and **const** are **Block-scoped** _(Scoped to the immediate enclosing block `{ }`)_.
> *   **var** variables are **Function-scoped** _(Scoped to the immediate function body `function() {...}`)_.
---
**Scope:** Determines the visibility and accessibility of variables and functions within different parts of your program.

**Block:** Any code enclosed within curly braces **`{ }`**, including functions, loops, and conditional statements.

&nbsp;

## 1. Function Scope vs. Block Scope
Notice how **var** variable escapes the inner block, but the **let** variable does not.

```javascript
function run() {
  // Function scope
  var foo = "Foo";
  let bar = "Bar";

  console.log(foo, bar); // 'Foo Bar'

  {
    // Block scope
    var moo = "Mooo";
    let baz = "Bazz";

    console.log(moo, baz); // 'Mooo Bazz'
  }

  console.log(moo); // 'Mooo' (var escapes the block)
  console.log(baz); // ❌ Uncaught ReferenceError: baz is not defined
}

run();
```

## 2. Nested Scopes & Shadowing
Variables with the same name can exist in different scopes without interfering with one another.

```javascript
var x = "global scope";

function foo() {
  var x = "function scope";
  console.log(x);
}

{
  let x = "block scope";
  // 'x' is only accessible in this enclosing block
}

foo();          // 'function scope'
console.log(x); // 'global scope'
```

## 3. Implicit Globals _(Missing Declarations)_
⚠️ If a variable is assigned without using **let**, **const**, or **var**, it automatically defaults to being **globally scoped**.

```javascript
{
  let a = 9;
  b = 8; // No keyword used! Becomes globally scoped.
}

console.log(a); // ❌ ReferenceError: a is not defined (block scoped)
console.log(b); // '8' (globally scoped)
```

### Accessing Global Variables:
Globally scoped variables are attached to the environment's global object:
*   🌐 **Browser:** Accessed via the **`window`** object.
    ```javascript
    console.log(window.b);
    ```
*   🖥️ **Node.js:** Accessed via the **`global`** object.
    ```javascript
    console.log(global.b);
    ```
