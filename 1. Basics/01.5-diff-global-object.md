## **let**, **const** & **var** - Creating Global object property

> 🎯 Difference 4 - Creating Global object property
> *   At the top level (global scope), **var** declarations *create* a property on the global object.
> *   **let** and **const** declarations *do not* create properties on the global object.
---
Variables declared using **let** and **const** are completely hidden from global objects like **`window`** _(in a browser)_ or **`global`** _(in Node.js runtime)_.

```javascript
var foo = "Foo"; // Globally scoped (creates global property)
let bar = "Bar"; // Not globally scoped
baz = "Baz";     // Implicit global (creates global property)

// 🌐 In Browser environment:
console.log(window.foo); // 'Foo'
console.log(window.baz); // 'Baz'
console.log(window.bar); // undefined

// 🖥️ In Node.js runtime:
console.log(global.foo); // 'Foo'
console.log(global.baz); // 'Baz'
console.log(global.bar); // undefined
```

### Memory Management
A key benefit of **let** and **const** variables not attaching to the global object is memory efficiency. By remaining block-scoped, they can be safely garbage-collected and **free up memory** as soon as their enclosing block finishes executing, unlike global properties which persist.
