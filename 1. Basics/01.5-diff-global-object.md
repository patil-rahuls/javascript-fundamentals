## **let**, **const** & **var** - Creating Global object property

> At the top level, **var** variables create a property on the global object.
>
> **let** and **const** variables do not.

Variables declared using **let** and **const** are not accessible to global objects like **window** in browser or **global** in Node.js runtime.

```javascript
// globally scoped
var foo = "Foo"; 

// not globally scoped
let bar = "Bar"; 

// globally scoped
baz = "Baz"; 

// In browser:
console.log(window.foo); // 'Foo'
console.log(window.baz); // 'Baz'
console.log(window.bar); // undefined

// In Node JS runtime:
console.log(global.foo); // 'Foo'
console.log(global.baz); // 'Baz'
console.log(global.bar); // undefined

```

The purpose of **let** and **const** declarations is only to free up memory when not needed in a certain block.
