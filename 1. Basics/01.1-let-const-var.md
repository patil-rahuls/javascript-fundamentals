## **let** _(ES6)_, **const** _(ES6)_ & **var**

> 🎯 Always default to **const** to minimize mutations and improve memory management.
>
> *   **`const`** - Use for objects and primitives that don't need to mutate/change.
> *   **`let`** - Use only when a variable *must* be reassigned.
> *   **`var`** - Avoid completely. It is the legacy way of defining variables and is highly error-prone.
---
&nbsp;

**Initialization Rule:** A **const** variable *must* be initialized at the time of declaration.

```javascript
// ❌ Incorrect:
const a; 
// Uncaught SyntaxError: Missing initializer in const declaration

// ✅ Correct:
const b = 2021;
const c = {}; // Allowed for Objects.
const d = []; // Arrays are a special type of Objects.
```

## Why **var** is Error-Prone

The following examples demonstrate how **var** variables can silently allow bad practices without throwing errors due to **hoisting** and **re-declaration**.

### 1. Silent Re-declaration
**var** allows you to declare the same variable multiple times.
```javascript
var name = "Rahul";
var name = "Raj"; // Works without error
```
*Functionally executes as:*
```javascript
var name = undefined;
name = "Rahul";
name = "Raj";
```

### 2. Assignment Before Declaration (Hoisting)
Variables declared with **var** are hoisted to the top of their scope and initialized with `undefined`.
```javascript
b = 25;
var b;
console.log(b); // 25
```
*Functionally executes as:*
```javascript
var b = undefined;
b = 25;
console.log(b);
```

### 3. Redundant Declarations are Ignored
```javascript
var a = 1;
var a = 2;
console.log(a); // 2

var a;
console.log(a); // 2
```
*Functionally executes as:*
```javascript
var a = undefined;
a = 1;
a = 2;
console.log(a);
var a; // Ignored because 'a' is already initialized
console.log(a);
```

### 4. Function Hoisting Priority
Function declarations are hoisted *before* any **var** initializer gets evaluated.
```javascript
var a = 1;
function a() {}

console.log(a); // 1
```
*Functionally executes as:*
```javascript
function a() {} // Function hoisted first
var a = 1;      // Variable initializer processed next

console.log(a); // 1
```
