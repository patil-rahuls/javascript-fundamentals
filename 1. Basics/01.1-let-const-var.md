## **let** (ES6), **const** (ES6) & **var**

> Use **let** and **var** to mutate primitive data.

> Use **const** for objects and primitives that don't need to mutate/change.

By default always use **const** if possible so that there are less mutations in the code.
It results in better memory management.

Avoid using **var** which is the old way of defining variables and its more error prone. That's the reason the **let** keyword was born!

> A **const** variable, while being declared, needs to be initialized.

```javascript
// ❌ Incorrect:
const a;
// 'Uncaught SyntaxError: Missing initializer in const declaration'

// ✅ Correct:
const b = 2021;
const c = {}; // Allowed for Objects.
const d = []; // Arrays are a special type of Objects.

```

## **var** variables can be more prone to errors.

All the following examples work without giving any error, but they look bad and erroneous.

> Example 1: **var** variables are initialized with the value **undefined** and are hoisted.

```javascript
var name = "Rahul";
var name = "Raj";
// This works without giving any error.

```
_Functionally, the code executes like this:_
```javascript
var name = undefined;
name = "Rahul";
name = "Raj";

```

&nbsp;

> Example 2

```javascript
b = 25;
var b;

console.log(b); // 25

```
_Functionally, the code executes like this:_
```javascript
var b = undefined;
b = 25;
console.log(b);

```

&nbsp;

> Example 3
```javascript
var a = 1;
var a = 2;
console.log(a); // 2

var a;
console.log(a); // 2

```

_Functionally, the code executes like this:_
```javascript
var a = undefined;
a = 1;
a = 2;
console.log(a);
var a; // This does not change the value of 'a' because it is already initialized.

console.log(a);

```

&nbsp;

> Example 4: Function declarations are hoisted before any **var** initializer gets evaluated.

```javascript
var a = 1;
function a() {}

console.log(a); // 1

```

_Functionally, the code executes like this:_

```javascript
// Function declarations are first hoisted.
function a() {}

// Then 'var' initializers are processed
var a = 1;

console.log(a); // '1'

```
