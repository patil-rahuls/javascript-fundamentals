## Short Circuiting **`&&`** and **`||`** - Practical Usage

> 🎯 Because **`||`** and **`&&`** return actual values rather than just booleans, they are incredibly useful for writing concise assignments and safe function calls.

---

### 1. Setting Default Values (Using **`||`**)
Useful for assigning a fallback or default value if the first operand is falsy.

```javascript
const myObj = {};

// ❌ Verbose (Using Ternary Operator)
const val1 = myObj.property1 ? myObj.property1 : 10;

// ✅ Better Solution (Using Short-circuiting)
const val2 = myObj.property1 || 10;
// Since myObj.property1 is undefined (falsy), 10 is returned and assigned.
```

### 2. Conditional Function Execution (Using **`&&`**)
Useful for checking if a function exists before attempting to execute it, preventing errors.

```javascript
const calcSq = function (val) {
  return val ** 2; // val^2
};

// ✅ Executes calcSq(34) ONLY if calcSq is truthy (i.e., it exists)
calcSq && calcSq(34);
```

---

#### 💡 Quick Rule of Thumb

*   **For Variables (Fallbacks/Defaults):** Use **`||`**
    ```javascript
    const age = myAge || 26;
    ```
*   **For Function Calls (Safety Guards):** Use **`&&`**
    ```javascript
    calcSq && calcSq(34);
    ```
